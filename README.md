#  로또 프로그램 (Lotto Game)

##  프로젝트 개요
- Java 21 기반으로 구현된 콘솔 로또 발매기입니다.
- 사용자가 입력한 금액만큼 로또를 자동으로 발행하고,  
  당첨 번호 및 보너스 번호를 입력받아 결과와 수익률을 계산합니다.
- MVC 패턴을 적용해 입력/출력, 로직, 데이터 구조를 명확히 분리했습니다.

---

##  학습 목표
- 관련 함수를 클래스로 묶고 객체 간 협력 구조를 설계한다.
- 단위 테스트를 통해 각 기능이 의도한 대로 작동하는 영역을 확보한다.
- 2주 차 공통 피드백(README, 함수 분리, 테스트 작성)을 최대한 반영한다.

##  기능 목록
> 기능 목록은 구현 과정에서 지속적으로 업데이트될 수 있습니다.  
> 정상 동작뿐 아니라 예외 상황도 포함합니다.

### 1. 입력
- 구입 금액 입력 (1,000원 단위, 유효성 검증)
    - [ERROR] 금액은 1,000원 단위로 입력해야 합니다.
- 당첨 번호 입력 (쉼표 구분 6개 숫자, 중복/범위 검증)
    - [ERROR] 로또 번호는 1~45 사이의 숫자여야 합니다.
- 보너스 번호 입력 (1~45, 중복 금지)

### 2. 로또 생성
- 금액에 따른 로또 개수 계산 (금액 / 1000)
- 1~45 사이 중복 없는 6개 번호 생성
- 번호 오름차순 정렬

### 3. 당첨 결과 계산
- 사용자 로또와 당첨 번호 비교
- 1~5등 당첨 여부 판단
- 총 수익률 계산 (소수점 둘째 자리 반올림)

### 4. 출력
- 구매 개수 및 로또 번호 출력
- 당첨 내역(등수별 개수) 출력
- 수익률 출력 (`총 수익률은 62.5%입니다.`)
- 예외 발생 시 [ERROR] 메시지 출력

###  예외 상황
- 금액이 1,000원 단위가 아닐 경우
- 로또 번호가 6개 미만 또는 초과일 경우
- 번호가 1~45 범위를 벗어날 경우
- 보너스 번호가 당첨 번호와 중복될 경우
